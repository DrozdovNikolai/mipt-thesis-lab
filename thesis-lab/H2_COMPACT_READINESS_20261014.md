# H2: компактный стенд для квоты Cloud.ru 8 vCPU

14.10.2026. **Локальная функциональная проверка прошла; облачная гипотеза
об экономии ещё не проверена.**

Квота допускает один системный узел и три ASR-узла по 2 vCPU / 4 ГБ.
Master оплачивается отдельно. Узлы имеют SSD 40 ГБ; ASR pod получает
1,5 CPU и 2 GiB. Это сохраняет три уровня параллелизма для сравнения
фиксированного пула, count и контроллера оставшейся работы.

Все локальные задания выполнялись с жёстким лимитом памяти 2 GiB и без
swap, в закреплённом CPU-образе:
`sha256:a410db19970c48afe507d872e065aa4d4ceed15feca3a5f4469144c589aadf5e`.
Модель tiny.en, Silero, код Firefly и число потоков не менялись.

| Проверка | Результат |
|---|---|
| Последовательные эталоны, два набора аудио 30/180/900 сек | 6/6 завершены |
| Повторы с проверкой полного нормализованного JSON | 6/6 совпали |
| Сравнение с эталонами прежнего pod 3 CPU / 5 GiB | 6/6 совпали |
| Падение worker после ASR до публикации результата | Задача восстановилась, принято одно завершение |
| Общее число завершённых логических задач | 13/13 |
| Восстановленная резервная БД | integrity_check=ok; 13 задач, 57 событий, 2 worker |
| Удаление контейнеров, сетей и тома этого запуска | Завершено |

Шесть первоначальных эталонов не имели `expected_sha` при постановке,
поэтому общий аудит относит их к `incorrect_or_unverified`. Это шесть
непроверенных на этапе приёма эталонов, а не шесть ошибочных распознаваний.
Для шести повторов и аварийного задания хеш результата проверен.

Сохранённый пик памяти 819 154 944 байт относится только к заменившему
процессу после намеренного сбоя, а не ко всей серии длинных записей.
Из этой величины нельзя делать вывод о максимуме памяти всех заданий.
Результаты получены на общем WSL-хосте и не используются для облачных
оценок задержки, производительности или рублёвой экономии.

API Cloud.ru для узла 2 vCPU / 4 ГБ / 40 ГБ вернул резерв Kubernetes:
70m CPU, 1 078 962 KiB RAM, 23 437 500 KiB диска. Реальное размещение
ASR вместе с системными DaemonSet необходимо проверить в облаке.
