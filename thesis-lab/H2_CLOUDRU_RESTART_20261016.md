## Исправления управления запуском

Потерянный ответ создания группы узлов сначала сверяется с полным списком
групп принадлежащего сеансу кластера. Найденная группа принимается только
при совпадении имени, кластера, размера, диска, сети, политики масштабирования
и размещения. API требует уникального имени группы; при повторе имя и запрос
сохраняются. Новый запрос допускается после 120 секунд подтверждённого
отсутствия группы, максимум три попытки в пределах 15 минут. При недоступной
инвентаризации повтор не разрешается. Задания ещё не принимаются на этом этапе.

Опрос уже известной облачной операции переживает временные ошибки чтения
в пределах прежнего срока ожидания. В журнале сохраняется тип транспортной
ошибки без секретов. Ошибки HTTP 500 при чтении также повторяются ограниченно.
Дашборд получает уникальное имя сеанса: в E его созданию мешало совпадение
названия с предыдущим сохранённым дашбордом.
