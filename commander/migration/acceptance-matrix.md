# Матрица приёмки миграции Commander на Vue 3

Матрица дополняет [план миграции](../MIGRATION_PLAN.md). Актуальная проверка: **8 октября 2026**, Vue M9, source baseline `e230b70` + зафиксированные working-tree hashes. **Пройдено** означает результат в указанном локальном окружении; **Частично** и **Ожидает** не закрывают весь сценарий. Доказательства и точные оставшиеся случаи сохранены в [acceptance-results.json](acceptance-results.json). Production не переключён.

Обозначения: **U** — unit, **C** — component, **E** — Playwright с controlled fixtures, **I** — интеграция с настоящим тестовым API, **V** — visual, **M** — ручная проверка. Новый UI может отличаться DOM-структурой, но бизнес-результат и доступное пользователю действие должны сохраняться. Поле «этап» указывает, когда сценарий должен быть впервые закрыт; M9 объединяет всю регрессию.
