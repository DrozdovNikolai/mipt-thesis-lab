# Переключатель ASR по шуму

Опыт завершён: исходный частично ручной dev остался 13,04%, его версии с шумом
5 dB улучшились 128,70% → 48,70%. Проверка исполнения PASS, независимая приёмка
не подтверждена. [Результат](../reports/cockpit-noise-router-v9/decision.md),
[запуск на своём аудио](cockpit_hybrid_local.md).

Этот опыт продолжает неудачный выбор по вероятностям текста из v8. Новый
классификатор получает только 62 характеристики звука, без слов и эталонов.
Обучение использует 231 старый чистый train-фрагмент и 3696 искусственных шумных
копий, всего 3927 наблюдений. Метка означает известный уровень добавленного шума.

Порог выбирается по предсказаниям с исключением каждого из девяти обучающих
дикторов, затем фиксируется. При высокой оценке сильного шума используется
исходный ответ Parakeet, иначе Whisper v5 balanced. Пустой ответ Parakeet
обрабатывается отдельно; русские контроли сохраняют прежний ответ Whisper.
[Полный протокол](../reports/cockpit-noise-router-v9/protocol.md).

PowerShell из корня проекта, после завершённых v5/v6/v8:

```powershell
docker compose -f compose.cockpit-noise-router-v9.yaml run --rm prepare
docker compose -f compose.cockpit-noise-router-v9.yaml run --rm train
docker compose -f compose.cockpit-noise-router-v9.yaml run --rm infer
docker compose -f compose.cockpit-noise-router-v9.yaml run --rm score
docker compose -f compose.cockpit-noise-router-v9.yaml run --rm checks
```

Все этапы локальные, CPU, без сети. Новых ASR-расшифровок и обновлений весов
распознавателей нет; обучается только классификатор шума. Его веса находятся в
`reports/cockpit-noise-router-v9/io-train/router.joblib`. Это локально созданный
joblib-файл, не пакет модели из внешнего источника. Завершённые файлы не заменяются.

Trainer получает только обучающее аудио и его происхождение. Inference получает
звук, кандидатов и зафиксированный классификатор, без эталонов/cohort/VAD. Scorer
затем сравнивает все 541 прежние записи, включая train-fit отдельно.

Одинаковое семейство синтетических искажений в train/dev ограничивает вывод:
даже хороший результат на этих смесях не доказывает работу на реальном неизвестном
кабинном шуме. Частичные и слабые dev прежние. Новые blind-dev и закрытый test
остаются нетронутыми, рабочая модель автоматически не заменяется.
