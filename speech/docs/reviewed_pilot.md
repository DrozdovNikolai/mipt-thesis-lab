# Результат частичной человеческой проверки

Пользователь сохранил девять подтверждённых расшифровок и один слабый черновик,
после чего сообщил, что остальные записи разобрать не может. Дальнейшая ручная
работа сейчас не требуется: сомнительные записи оставлены без подтверждения.
Человеческие ревизии не перезаписывались и не исправлялись автоматически.

Один подтверждённый train-фрагмент заканчивается на `seat-`. Он отложен вне
обучающей выборки до обработки обрыва: дефис сам по себе не создаёт scoring mask.
В `data/curated/reviewed-pilot-v2` зафиксированы **3 train и 5 dev** расшифровок,
соответственно 2 и 3 speaker-группы. Исходные A/C группы сохранены. Отсутствующие
и неподтверждённые записи перечислены в `plan.json`; test не читался.
Пустой `reviewed-pilot-v1` относится к неудачной первой подготовке и не является
готовым набором данных.

При первом экспорте обнаружилась ошибка: проверка графа на частично размеченном
подмножестве меняла ожидаемый group ID. Экспортёр теперь проверяет полный исходный
пакет и неизменность group ID каждой ревизии, затем сохраняет исходные группы
в выбранном подмножестве. Новый regression test проверяет частичный экспорт
и отказ при подмене группы в ещё не размеченной записи. Все 20 тестов sidecar
и экспорта прошли; прежние 248 тестов приложения относятся к предыдущей проверке.

[Отчёт сравнения](../reports/reviewed-pilot-v1/report.md) содержит 50 пересчитанных
предсказаний — восемь прежних ASR pipeline вариантов и две модели в опыте A5.
Новый ASR inference и новое обучение в этом шаге не запускались: использованы
сохранённые ответы с проверкой audio hashes. Для A5 дополнительно проверено
побайтовое совпадение массивов аудио после того же resampling до 16 кГц.
Эталонные слова не подавались в модель, prompts или hints.

| Опыт | До | После | Вывод на доступной подвыборке |
|---|---:|---:|---|
| Pipeline A0–A4 и dev-search, small/int8 CPU | A0: 19 ошибок / 115 токенов | Все дополнительные варианты хуже | Этапы не активированы |
| A5, исходный checkpoint против LoRA, float16 GPU | 34 / 115 | 30 / 115 | −11,76%, статистического подтверждения нет |

A5 paired cluster bootstrap: 95% интервал разности долей ошибок
«адаптированная − исходная» **[−0,06522; 0]**, три группы, 2000 повторов, seed 55.
Он включает отсутствие эффекта. Кроме малого объёма, выборка состоит только из
разобранных записей, разметчик видел подсказки, а один dev-текст использует
цифровую запись чисел (`1.0.1.6`, `3000`, `300`) с несогласованными lexical conventions.
Сохранённая орфография не исправлена машиной; эти подсчёты не выдаются за финальный
независимый lexical WER. Цифровые записи в train также отмечены в плане.

Состав нового dev-подмножества отличается от семи автоматически привязанных пар
прошлого эксперимента. Числа 11,76% и 18,57% не являются измерениями на одном
и том же эталонном наборе. Критические сущности, event/salience и temporal labels
по-прежнему отсутствуют. **ASR/NLP quality: NEEDS_MORE_DATA; статистическое
подтверждение: INCONCLUSIVE; candidate не выбран, release не изменён.**

Выполненная подготовка PowerShell; повтор требует нового имени выходного каталога:

```powershell
docker run --rm --network none --entrypoint python -v "${PWD}/scripts:/app/scripts:ro" -v "${PWD}/data/curated/annotation-packet-v1:/packet:ro" -v "${PWD}/data/curated:/curated" -v "${PWD}/reports:/reports" north55-speech:login-fix-v1 -m scripts.score_reviewed_pilot prepare
```

Выполненный пересчёт, который можно повторить на замороженных файлах:

```powershell
docker run --rm --network none --entrypoint python -v "${PWD}/scripts:/app/scripts:ro" -v "${PWD}/data/curated/reviewed-pilot-v2:/reviewed-pilot-v2:ro" -v "${PWD}/reports:/reports" -v north55-speech_audio_data:/audio:ro north55-speech:login-fix-v1 -m scripts.score_reviewed_pilot score --output /reviewed-pilot-v2
```

На Linux замените `${PWD}` на `$PWD`; фактические измерения получены из PowerShell
в Linux-контейнере. Скрипт требует совпадения замороженных ссылок на данные,
scorer и исходные отчёты. Правила и пороги ACCEPTANCE не менялись.
