# SOTERIA: новые записи экипажей и машинные черновики

Источник — NASA SOTERIA Simulation Testbed Data, CC BY 4.0:
https://registry.opendata.aws/nasa-soteria-data/ .
Это записи тренажёра, включающие экипаж, радиообмен и исследователей.

Для первого опыта до распознавания выбраны Crew_01–Crew_04. Для каждого взят
наименьший DVR MP4 размером не менее 512 MiB среди Case 1, 2, 3, 5, 6, 7.
Так исключены короткие технические обрывки; выбор не зависит от ответа ASR.
Всего четыре полных видео, 4,916 ГБ. Crew_01/03 предварительно отведены под
train, Crew_02/04 — под dev. Остальные экипажи в этом опыте не открываются.

Экипажи разделены, но независимость всех голосов пока не установлена:
диспетчер и исследователи могут повторяться. Идентификаторы отдельных
дикторов и роли не выдумываются. До обучения или независимой проверки
нужно уточнить область реплик и присутствие общих участников.

## Обработка

- Загрузка с If-Match, возобновлением по Range и проверкой полной длины,
  SHA-256 и multipart ETag. Оригиналы сохранены.
- FFmpeg выделяет всю аудиодорожку, сохраняя каналы и переводя её в 16 кГц.
  Для ASR каналы усредняются; сильное взаимное подавление останавливает обработку.
- Silero VAD отмечает речь; короткие соседние реплики объединяются до 22 секунд.
  Сохраняются все найденные интервалы, без квоты на запись и отбора по ASR.
  Граница возле паузы не гарантирует конец предложения. Пропущенную VAD речь
  можно позднее восстановить из полных исходных дорожек.
- Каждый вырезанный WAV побитно сравнивается с соответствующими отсчётами
  моносигнала. Проверяется, что все интервалы VAD покрыты ровно один раз.
- Whisper large-v3 создаёт черновики с автоматическим определением языка.
  Whisper small даёт второй ответ для диагностики расхождений.
  Человеческие тексты и галочки проверки автоматически не создаются.

Модели работают локально на GPU 0, без сети, без сценариев и текстовых подсказок.
Код, политика обработки, список источников и настройки сохраняются в отчёте.
Согласие двух моделей не означает правильность; расхождения не являются WER.
Обучение и переключение рабочей модели в этот опыт не входят.

## Запуск и разметка

```powershell
./scripts/Run-SoteriaV14.ps1
```

Повтор использует проверенные сохранённые аудио и предсказания. При изменении
идентичности входа обработка останавливается. Для нового опыта нужен новый пакет.

[Контрольная очередь](http://localhost:8013/?split=dev) ·
[Обучающая очередь](http://localhost:8013/?split=train).

Очередь чередует экипажи. Кнопка «Подставить машинный черновик» заполняет только
пустое поле. Прослушайте запись и исправьте слова; область «Тренажёр» подходит
для реплик экипажа в симуляторе, «Pilot–ATC» — для радиообмена. Не угадывайте
неразборчивые слова и роли. Если реплики смешаны, не подтверждайте однородную
область без дополнительного разбиения. Старые очереди BLeRIOT остаются отдельно.

Артефакты: `reports/soteria-v14/result.json`, `preparation.json`,
`packet-verification.json`, `experiment-plan.json`, `acquisition.json`.
Полные черновики и диагностика хранятся локально; в Git не добавляются.
Число фрагментов и длительность нужно брать из фактически завершённого
`result.json`, а не оценивать по размеру скачанных видео.
