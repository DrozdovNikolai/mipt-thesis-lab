# Обучение без новой ручной разметки

Эксперимент использует прежние 247 слабых пар: 231 оригинальный интервал и 16
парных шумовых копий. Исходные тексты, дикторы и разбиение train/dev сохранены.
Созданные акустические варианты не увеличивают объём независимой речи.

Три режима с одинаковой исходной моделью и начальными адаптерами:

| Режим | Речевых предъявлений | Дополнительных неречевых |
|---|---:|---:|
| uniform | 960, прежняя равномерная выборка | 0 |
| balanced | 960, балансировка и акустические искажения | 0 |
| balanced-silence | Тот же поток, что у balanced | 240, вес loss 0.1 |

Каждый режим выполняет 240 обновлений AdamW. Обучаются только адаптеры декодера,
KL не используется. Кодировщик звука и все исходные веса остаются неизменными.

В сбалансированном потоке сложные исходные реплики и их варианты занимают
480 предъявлений вместо 95 в прежнем режиме. Всего создаются 420 разных
акустических вариантов с заданным шумом, простыми ранними отражениями,
изменением громкости и маскированием небольших участков спектрограммы.
Каждое такое предъявление имеет собственный seed; готовые состояния замороженного
энкодера кешируются после применения всех искажений.

Дополнительные неречевые сигналы полностью синтетические. Они не содержат
человеческих голосов. Цель обучения — специальный токен Whisper `<|nocaptions|>`
с последующим EOS, после начального SOT. Обычная пустая строка не заменяет этот
контракт. Дополнительный неречевой проход сохраняет генератор случайности
речевого прохода, чтобы dropout не смешивал два сравниваемых эффекта.

Проверка включает прежние 441 вход (из них 247 — диагностика подгонки train),
80 новых шумовых версий 40 старых кабинных dev и 20 синтетических неречевых
контролей с отдельными seed. Варианты dev сохраняют прежние эталоны и группы;
новыми независимыми записями они не считаются. Все модели оцениваются как
напрямую, так и с одинаковым фильтром наличия речи.

Новые 42 контрольных фрагмента очереди ручной разметки и закрытый test в этот
опыт не входят. Рабочая конфигурация не меняется по результату диагностики.

Запуск из корня проекта:

```powershell
python -m scripts.run_cockpit_robust_v5 init
python -m scripts.run_cockpit_robust_v5 freeze
python -m scripts.run_cockpit_robust_v5 tests
python -m scripts.run_cockpit_robust_v5 train
python -m scripts.run_cockpit_robust_v5 convert
python -m scripts.run_cockpit_robust_v5 vad
python -m scripts.run_cockpit_robust_v5 baseline
```

После конвертации для каждого ARM (`uniform`, `balanced`, `balanced-silence`):

```powershell
python -m scripts.run_cockpit_robust_v5 candidate ARM
python -m scripts.run_cockpit_robust_v5 cpu ARM
```

Затем `audit` и `score`. Подготовка и обучение защищены от перезаписи;
для нового опыта нужны новые каталог и том. Повторное распознавание проверяет
идентичность ранее сохранённых ответов.

Все новые веса лежат в отдельном Docker volume `north55-speech_cockpit_robust_v5`:
`models/whisper-small-cockpit-robust-v5-{ARM}`. Контрольные суммы, состояния
оптимизатора, планы и логи сохранены вместе с результатами опыта.
