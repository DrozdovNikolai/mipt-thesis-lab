# Сравнение с другим семейством ASR

Parakeet TDT 0.6B v2 сравнивается с сохранёнными Whisper small и тремя режимами v5.
Это английский диагностический эксперимент. Приёмка по SPEC и качество RU им не
проверяются. В рабочем сервисе сохраняется прежняя модель.

Входы: 491 прежний английский/неречевой контроль, включая 247 обучающих фрагментов,
и 352 отклонённых train-кандидата. Первые 491 имеют побайтно тот же float32 звук,
что использовали Whisper. Контрольные эталоны и тексты для отбора не монтируются
в контейнер распознавания. Новые blind-dev и закрытый test не используются.

Файлы в `reports/cockpit-cross-asr-v6/`; модель и копии входного аудио хранятся
в Docker volume `north55-speech_cockpit_cross_asr_v6`.

Для уже подготовленного стенда, из корня проекта:

```powershell
docker compose -f compose.cockpit-cross-asr-v6.yaml build runtime
docker compose -f compose.cockpit-cross-asr-v6.yaml run --rm acquire
docker compose -f compose.cockpit-cross-asr-v6.yaml run --rm prepare
docker compose -f compose.cockpit-cross-asr-v6.yaml run --rm infer
docker compose -f compose.cockpit-cross-asr-v6.yaml run --rm score
```

`acquire` — явное получение весов NVIDIA фиксированной revision, сеть доступна
только ему и сборке зависимостей. Остальные стадии работают без сети.
`prepare` и `score` отказываются перезаписывать завершённый опыт. Для нового опыта
нужен новый каталог и план. `infer` проверяет сохранённые ответы и возобновляет
только недостающие входы; законченный прогон повторно не вычисляется.

Первая попытка загрузила модель, но завершилась до распознавания: конфигурация
NeMo содержит Enum, несовместимый со строгим JSON. Обёртка в
`runtime-amendment-r2/` сохраняет имена Enum и загружает исходный зафиксированный
скрипт по абсолютному пути, обходя конфликт с установленным пакетом `scripts`.
Она не меняет веса, параметры декодирования или исходный frozen-код. Причины
и хеши зафиксированы в `amendment.json`; журналы неудачных запусков сохранены.

Оценка использует прежний lexical WER/CER; числовая нормализация — дополнительная
симметричная метрика. Согласие Parakeet и Whisper с поддержкой чек-листа даёт
только слабую обучающую метку. Восстановление считает новое покрытие исходных
временных интервалов, отдельно от суммы длительностей нарезок.
