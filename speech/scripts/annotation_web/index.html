Категории фрагмента
Выбирайте вручную. Это классификация фрагмента; временные события размечаются отдельно.
Сущности, временные события и неразборчивые участки
Таймкоды start_sec/end_sec — от начала фрагмента. Пустое поле означает отсутствие разметки; [] — проверенное отсутствие только при отмеченном подтверждении. Сущности: type, canonical_value, unit, polarity, start_sec, end_sec. Полярность: affirmative / negated / uncertain. Для временных событий: labels, start_sec, end_sec.
Оценка temporal detection на полных записях требует отдельного набора. Для unintelligible дополнительно нужны reference_start_token/reference_end_token.
