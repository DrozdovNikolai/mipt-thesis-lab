# NUS: новый адаптер только для декодера

Реализовано и выполнено. Целостность артефактов: **PASS**. Точное исполнение frozen-протокола: **FAIL**. Итоговый candidate: **FAIL**. Независимая оценка: **NEEDS_MORE_DATA**.

Одна траектория с исходного Whisper-small: 675 прежних пар (275 NUS, 200 EN, 200 RU), 94.35 минуты. Нет новых расшифровок, исправления текстов и пересмотра splits. NUS — одна общая train-группа с неизвестными говорящими и без локальной полной человеческой сверки текста. Готовые тексты пригодны для обучения, но не заменяют gold.

Обучались только 589824 параметра LoRA в 48 decoder q/v projections, 96 тензоров. Веса encoder побайтно проверены до/после обучения, в checkpoints и после merge. Это новый decoder-only train с самого начала, а не отключение части совместно обученного адаптера.

Выполнены 1200 шагов цикла и 4794 позиций загрузчика; контрольные точки 240 и 1200. Фактические счётчики AdamW: {'240': [239.0], '1200': [1199.0]}. Первые 240 шагов — прежний спад LR 5e-5; следующие 960 — constant 2e-5. Моменты AdamW сохранялись. Seed 55, rank 8, alpha 16, dropout .05, batch 1/accumulation 4, FP16/TF32 off. Итоговая точка 1200 задана до обучения, dev early stopping отсутствует.

Если AdamW-счётчик меньше номера шага цикла, FP16 scaler пропустил обновление. Такой пропуск не подменяется выполненным шагом и не компенсируется дополнительным обучением после исчерпания frozen-бюджета; нарушение точного числа updates отражено в protocol_execution и artifact_verification. Метрики сохранённых весов всё равно измеряются.

Дополнительно проверен сохранённый optimizer прежнего joint240: у него тоже 239 фактических AdamW updates при 240 шагах Trainer. Его hash соответствует прежнему training.json; старые веса и ответы не менялись. Обе ранние точки сравниваются с одинаковым фактическим числом обновлений (optimizer-audit.json).

## Проверки и ограничения

868 новых GPU ASR-вызовов, 4 CPU smoke (EN и RU для обеих точек), 40 тестов. Сеть выключена; inference не получает эталоны. Исходные volumes только для чтения. Hash-проверки, effective options и PCM связывают ответы с теми же входами. Для старых ответов без runtime PCM отдельно записана реконструкция из исходного файла, не выдаваемая за исторически записанный checksum.

PowerShell/Linux пересчёт: cross-platform-replay.json. Per-sample S/D/I: scored-counts.json. Параллельные ASR-процессы не используются для заявления о скорости.

Не хватает независимых ≥300 кабинных фрагментов / ≥3000 слов / ≥20 групп, 100 проверенных сущностей, а также event/temporal разметки для NLP. RU/mixed cockpit не подтверждены общим RU-контролем. Пороги ACCEPTANCE не менялись, исходный release dev-search остаётся исчерпанным, промежуточная точка не выбрана задним числом. Разные адаптированные веса не являются сравнением pipeline-добавок на одном checkpoint. В рабочем сервисе сохранена исходная модель.
