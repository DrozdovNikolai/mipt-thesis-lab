# Поиск данных, доступных без переписки

Проверка: 14 сентября 2026 года. Найден новый разрешённый источник записей тренажёра
NASA SOTERIA и открытая текстовая разметка Boeing. Нового корпуса, одновременно
закрывающего кабинные аудио, точные человеческие расшифровки и требования независимого
test, пока не найдено. Письма, заявки на доступ и покупки не выполнялись.

## NASA SOTERIA: доступны реальные файлы

[Реестр AWS](https://registry.opendata.aws/nasa-soteria-data/) указывает NASA как
держателя, CC BY 4.0 и анонимное скачивание из `s3://nasa-soteria-data/`.
В [статье авторов](https://www.nature.com/articles/s41597-025-05336-7) описаны
24 коммерческих пилота и работа экипажей в тренажёре; записи содержат как общение
экипажа, так и ATC. Проверенные экспертами расшифровки в статье 2025 года указаны
среди планируемых дополнений. Это не подтверждение их наличия сейчас.

Фактически выполнено:

- Анонимно прочитан полный каталог: **11 143 объекта**, около **1,418 ТБ**.
  [Сводка](soteria-inventory/summary.json), [индекс медиа](soteria-inventory/media.json),
  [хеши страниц](soteria-inventory/pages.json). Это объём каталога, не скачанный объём.
- Есть **115 MP4**, **12 M4A**, 12 каталогов экипажей. Нельзя считать каждый файл
  независимой сессией: возможны повторы и продолжения одной записи.
- Из 84 объектов с расширением WAV **83 имеют размер 46 байт**. Поэтому наличие
  расширения WAV не выдаётся за наличие пригодной речи. Основной источник — видео DVR.
- По именам не найдены transcript/annotation/SRT/VTT/TextGrid/EAF. TXT относятся
  преимущественно к письменным EventReport и метаданным. Полное содержимое всех
  11 143 объектов не исследовалось; утверждения, что расшифровок нигде нет, не делаем.
- До чтения аудио выбран самый маленький MP4 из `Crew_02/DVR`:
  `DVR10_Case_1_SOTERIA_20220504-170006Z_S1R1.mp4`, **90 608 135 байт**.
  Скачан целиком, длина и multipart ETag проверены; сохранён SHA-256 оригинала.
  [План](soteria-sample-plan.json), [получение](soteria-acquisition.json).
- Offline FFmpeg успешно выделил **86,955 секунды, 48 кГц, 2 канала**; оба канала
  ненулевые. Проверено декодирование, а не точность речи или происхождение голоса.
  [Фактическая проверка](soteria-audio-verification.json).

Оригинал и WAV находятся в `data/input/nasa-soteria-v1/` и не публикуются в Git.
`Crew_02` теперь только discovery/dev: связанные записи не должны становиться
независимым final test. Сегменты ATC надо исключать из основной задачи; роли по
голосу не определялись. 12 экипажей сами по себе не обеспечивают 20 независимых
групп из ACCEPTANCE. **Статус: файл доступен и проверен технически; готовых
обучающих пар нет; ASR gate — NEEDS_MORE_DATA.**

## Boeing: готовая исходная разметка для дополнительного NER

[Датасет](https://huggingface.co/datasets/boeing/aviation-ner-BIO) имеет MIT в карточке.
[Авторы](https://huggingface.co/boeing/aviation-ner) описывают извлечение сущностей
из Service Difficulty Reports: компонентов, неисправностей, фаз полёта и действий.
Это технические отчёты, не расшифровки кабинных разговоров.

Получен только издательский `train.10.23.bio.json` на revision
`36832b83a85b15936b6f2dd15c7cd886194a9535`: **894 записи, 66 507 токенов**, 986 339 байт.
Сверены размер, Git blob SHA-1 издателя и локальный SHA-256. Структура токенов и
границ исходных меток прошла проверку. [Получение](boeing-acquisition.json),
[проверка структуры](boeing-structure.json). Исходный test не скачивался.

Человеческое происхождение всех меток и независимые session IDs не установлены.
Теги не преобразованы в наши события, значимость или human-verified critical entities.
**Статус: дополнительный текстовый материал получен для изучения; обучение и NLP
gate не выполнялись.** Локальный путь: `data/input/boeing-ner-v1/`.

описывает оценку речи пилотов в VR. Проверен полный Git tree revision
`0c520edbcd345cb9005cc77c3345eedbfef7147b`: присутствуют `Sample01`–`Sample07.parquet`,

Для `Sample01.parquet` прямой анонимный Range GET вернул **HTTP 206** и сигнатуру
`PAR1`; заявленный размер 1 705 625 байт. Прочитаны только первые четыре байта,
не аудио и не test-ответы. [Проверка](vr-file-probe.json).
Лицензия не найдена в README и дереве, GitHub API сообщает `license: null`.
**Статус: доступность файла подтверждена; обучение и benchmark импорт не разрешены
текущей проверкой источника.** Содержимое Parquet, качество разметки и группировка
не проверены. Результаты авторов не переносятся на наш проект.

## Команды и границы выполненной работы

Из корня репозитория, Python 3.11+; в Linux используйте `python3` вместо `python`.
Инвентаризации требуют новой выходной папки, чтобы сохранять предыдущие снимки.

```sh
python scripts/discover_direct_datasets.py --output reports/direct-data-search-v2/discovery
python scripts/inventory_soteria.py --output reports/direct-data-search-v2/soteria-inventory
python scripts/acquire_boeing_ner_support.py
python scripts/acquire_soteria_sample.py
python scripts/inspect_soteria_sample.py
```

Первые две команды создают новый снимок текущего каталога. Команды получения
закреплены на проверенных исходниках v1; SOTERIA использует сохранённый список v1.
Последняя требует уже имеющийся `north55-speech-gpu:0.1.0` с FFmpeg, GPU не нужен;
Docker запускается с `--network none`. Повторная проверка использует локальные файлы.

Реализованы и исполнены поиск, инвентаризация, ограниченное получение и проверка
файлов. Windows: все перечисленные виды действий реально выполнены.
Ubuntu WSL: `python3 scripts/inspect_soteria_sample.py` повторно исполнил offline
FFprobe и проверку уже полученного PCM; число кадров, RMS и SHA-256 совпали с Windows.
Само декодирование в WAV выполнено на первом Windows-запуске, повторным не объявляется.
Оба отчёта сохранены: `windows-audio-verification.json` и `soteria-audio-verification.json`.
Новые ASR/NLP обучение, WER/F1, человеческое прослушивание, temporal-разметка и
quality gate не выполнялись. Исходные SPEC/SOURCES/ACCEPTANCE, аннотации,
предыдущие результаты и рабочий baseline сохранены. Candidate не продвигался.
