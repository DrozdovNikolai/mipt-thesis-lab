# Проверка готовых англоязычных кабинных аудиотекстовых данных

Проверено 14 сентября 2026 года. Выполнены поиск первичных публикаций и каталогов, чтение деревьев GitHub и непосредственная проверка двух опубликованных Parquet-файлов. Обучение и ASR не запускались, данные в benchmark не импортировались, письма и покупки не выполнялись.

**Подтверждённые варианты:** HIWIRE — поставляемый по лицензии английский корпус коротких команд с транскрипциями; NUS — открыто скачиваемые подготовленные английские аудиотекстовые файлы небольшого объёма, но разрешение на повторное использование не установлено. Полноценный свободно лицензированный корпус естественных английских диалогов экипажа с точной разметкой и достаточным независимым test в этом поиске не найден. Поиск не объявляется исчерпывающим.

**HIWIRE.** Первичный каталог ELRA был доступен при прямом HTTP-чтении; цена также отражена в [ELG](https://live.european-language-grid.eu/catalogue/corpus/2059). Это 81 неноситель английского: 31 француз, 20 греков, 20 итальянцев, 10 испанцев. Исходные записи начитаны людьми, шумовые версии созданы с шумом кабины. Наличие sentence transcriptions подтверждено авторами в [Gemello et al., Interspeech 2007, §5.1.2](https://www.isca-archive.org/interspeech_2007/gemello07_interspeech.pdf). Подходит как готовый материал для исследования английских авиационных команд и устойчивости к шуму. Не считать чистую запись и три её копии независимыми примерами; не выдавать суммарные часы всех вариантов за уникальную речь. Текущие условия поставки и назначение лицензии надо сверить при оформлении; покупки не было.

**NUS: проверены именно файлы.** Репозиторий проекта Singapore Airlines–NUS Digital Aviation Corp Lab, revision `0c520edbcd345cb9005cc77c3345eedbfef7147b`. В [отчёте авторов, §4.3.1](https://wangyubo013-blip.github.io/CDE4301-VR-401-Final-Report/) описано получение фрагментов из записей тренажёра, ручная привязка времени и подготовка текста. Это описание происхождения авторов; независимая проверка всех слов по аудио здесь не выполнялась.

Суммарно скачано 16 467 443 байта. Размеры и вычисленные Git blob SHA-1 совпали с GitHub tree. В каждой строке действительно присутствуют встроенные WAV bytes и непустой `text`; также есть id, временные поля и duration. Все WAV успешно прочитаны, между двумя файлами нет точных PCM-дубликатов. Семь префиксов `clip01`–`clip07` не объявляются семью независимыми дикторами или сессиями. Повторение сценариев по тексту видно, полноценная проверка зависимости и scope не выполнялась.

В текстах есть, например, `Flaps 30` и `Captain wrong runway`, а также обращение к диспетчерской вышке. Поэтому все 313 строк нельзя автоматически включить в целевой cockpit-only набор. GitHub API возвращает license=null, LICENSE отсутствует в полном дереве, README и страница проекта не устанавливают разрешение на обучение/перераспространение. Это причина обозначать источник кандидатом для согласования использования, а не уже допущенным датасетом. Скачанные файлы оставлены только для локальной инспекции и исключены из Git локальным .gitignore.

Проверяемый результат сохранён в [parquet-inspection.json](C:/DEV/MIPT/Diploma/Speech/reports/english-ready-data-search-v1/parquet-inspection.json); собственный скрипт — [inspect_parquet.py](C:/DEV/MIPT/Diploma/Speech/reports/english-ready-data-search-v1/inspect_parquet.py). Проверка исполнена без сети в существующем контейнере north55-speech-train:publisher-v2, без моделей и эталонов проекта.

**Дополнительные проверки.** Полное дерево [репозитория автора DLR](https://github.com/kartheekkumar65/Analyzing-and-Fine-Tuning-Whisper-Models-for-Multilingual-Pilot-Speech-Transcription-in-the-Cockpit) содержит в All_Segments только один MP3 размером 28 461 байт и соответствующий короткий немецкий текст. Это не опубликованный исследовательский корпус. IEM Pilot Speech Database не подтвердил доступный комплект точных транскрипций; EARS предлагает обращаться к авторам; Noort CVR публикует таблицы текста, без набора аудиопар.

Hugging Face API проверен по запросам cockpit (3 результата), aviation (достигнут лимит 100), pilot speech (6), flight speech (0), crew speech (0), flight simulator (0), checklist (достигнут лимит 100). Поэтому широкие выдачи не объявляются полностью просмотренными. Oye12/A_Pilot_Speech_Corpus относится к банковской биометрии: pilot означает пилотное исследование. ICSRC относится к автомобильной китайской речи. ATCOSIM/ATCO2/Airbus ATC имеют смежную область радиообмена и не подменяют диалоги экипажа. BLeRIOT уже скачан в проекте, нового корпуса им не объявляем.

Для быстрого старта с готовой лицензируемой EN-разметкой заслуживает рассмотрения HIWIRE. Для наиболее близкого небольшого набора — NUS после установления условий использования. Для более объёмных естественных тренажёрных диалогов с готовыми эталонами остаётся адресный запрос DLR. Ни один вариант ещё не измерялся моделями north55_speech в рамках этого поиска.
