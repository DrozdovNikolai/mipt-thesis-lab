Отсутствующие границы не заменены вымышленными. В text-режиме встретились повторяющиеся последовательности символов на шуме/сильной смеси, для которых backend не вернул word alignment. Они сохранены и входят в lexical scoring; длинная последовательность без пробелов может считаться одним вставленным словом, поэтому слов/мин недостаточно для описания такого сбоя.

## Исполнение и ограничения

- 1084 новых GPU-прогноза, 500 проверенных прежних baseline-ответов; ошибки: 0.
- CUDA float16 у всех GPU-вариантов; 16 отдельных CPU smoke. CPU качество не смешивается с GPU-метриками.
- Проверка артефактов: **PASS**, 73 проверок. Технический PASS не означает ML PASS.
- Проверены хеши источников, весовых манифестов, эталонов, предсказаний и отсутствие доступа inference к эталонам/controls/train.
- Выравнивание проверяет диапазон координат, не точность относительно человеческой временной разметки. Нулевые длительности и отсутствие выровненных слов сохранены в comparison.json.
- Quiet-копии сохраняют оригинальную группу. Их нельзя считать независимыми дополнительными эталонами.
- Критические сущности и временные границы коротких команд недостаточны: **NEEDS_MORE_DATA**. NLP/temporal detection не переобучались и не получили новых человеческих labels.
- RU измерен на общей речи; кабинный RU и mixed остаются неподтверждёнными.
- Повторы не удалялись. Несоответствие повторов эталону само по себе не доказывает галлюцинацию.
- В рабочем сервисе остаётся small / CPU int8 / baseline. Ни один диагностический вариант не продвинут.

Команды, структура файлов и ограничения: `docs/decoding_diagnostics.md`.
