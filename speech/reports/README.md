по 160 обновлений, 470 новых распознаваний. В смесь вошли 63 новых слабых

здесь может зависеть от подсказки при разметке; это не независимая приёмка.

без объявления такого сравнения человеческим WER. Рабочий сервис не переключался.

В Git сохраняются итоговые отчёты, графики, агрегированные измерения, протоколы,
планы, проверки исполнения, сведения об источниках и контрольные суммы.
Каталоги `frozen/` содержат точный код исторических экспериментов: это часть
воспроизводимости. Для `reports/` отключено преобразование переводов строк в Git,
чтобы сохранить байтовые SHA-256, включая зафиксированные версии исходников.

В `.gitignore` исключены веса, исходные данные, секреты, кэши, журналы, скачанные
HTTP-ответы, снимки контейнеров и массовые ответы ASR/NLP. Большие `comparison.json`
с повторяющимися ответами тоже остаются локальными. Файлы не удалены с диска.
Небольшие smoke-отчёты и текстовые примеры, необходимые для объяснения результатов,
сохранены; этот каталог не является обезличенным экспортом всех материалов.

Рядом с исключёнными ASR-сравнениями находятся `metrics-summary.json`: все поля
агрегированных результатов скопированы без пересчёта, а массив отдельных ответов
заменён указанием количества записей и SHA-256 исходного файла. Для раннего
dev-прогона используется `pending-dev-ablation-summary.json`. Экспорт повторяется
из корня репозитория одинаковой командой в PowerShell и Linux:

```sh
python scripts/export_git_report_summaries.py
```

Скрипт не перезаписывает исходные отчёты и не меняет quality gates. При отсутствии
локального исходника он сообщает `SKIP` и оставляет сохранённую сводку на месте.
Отдельное небольшое NLP-сравнение `additional-sources-v1/nlp-final/comparison.json`
содержит агрегированные precision/recall/F1 и сохраняется целиком.

Клон Git содержит результаты и код, но не полный пакет исполнения. Ссылки в
исторических документах на исключённые файлы требуют локального пакета артефактов.
Для повторного подсчёта и проверки всех исторических хешей нужны сохранённые
сырые ответы, планы, аннотации и данные по исходным путям. Для нового ASR-прогона
дополнительно нужны веса и аудио, полученные по разрешённым источникам из
`SOURCES.md`; используйте инструкции соответствующего эксперимента в `docs/`.
Новые измерения нельзя выдавать за байтовую копию старого исполнения.
