# Ограниченный поиск практического улучшения

Новый запуск явно разрешён пользователем: «делай ЧТО УГОДНО ... лишь бы получить
уже какой-то улучшенный результат». Это новый бюджет, старые протоколы и результаты
не переписываются. Обучение не требуется для проверки перечисленных гипотез.

До распознавания фиксируются входы, тексты, алгоритм словаря, модели и параметры.
Основная новая проверка: исходный small против заранее выбранного large-v3 на
ранее не использованных русских предложениях FLEURS dev. Используются все доступные
записи, но основной результат берётся по одной записи на sentence ID, выбранной
по SHA256 имени до ASR. Исключаются sentence IDs всего имеющегося FLEURS train
и 50 ранее оценивавшихся dev-предложений. Это общая читаемая RU-речь; неизвестные
дикторы не позволяют построить достоверный speaker/session bootstrap.

Отдельный exploratory-поиск на прежнем dev: small/large × без словаря/со словарём
из train × без неречевого фильтра/с фильтром. Не более восьми конфигураций,
никакого изменения параметров после просмотра результатов. Словарь: до 48
английских слов из кабинного train, минимум два вхождения, ранжирование по
сглаженному отношению частот к общей EN train-речи; числа исключаются.
Словарь подаётся только при явно заданном EN; язык никогда не выводится из эталона.
Неречевой фильтр: Silero .5/100 ms, при наличии речи сохраняется всё исходное окно.
Фильтр не исправляет текст ASR. Совпадающие вызовы переиспользуются с provenance.

Для выбора английского экспериментального варианта требуются: отсутствие runtime
failures; clean EN WER не хуже исходного больше чем на 1 п.п.; тихая речь не хуже
исходного; оба шума не хуже исходного; затем минимальный human cockpit dev WER,
затем слабый publisher dev WER, затем более простая конфигурация. При отсутствии
допустимого улучшения остаётся исходный EN. Автоматическая языковая маршрутизация
может использовать только заявленный язык: RU -> large, остальное -> выбранный EN
или исходный small. Новая RU-проверка не используется для подбора модели/параметров.

Старые 5 human cockpit фрагментов сохраняют статус exploratory. Слабые сценарные
тексты не переименовываются в человеческую разметку. Старый закрытый test не
открывается; всё обучение и его source-группы остаются вне независимой оценки.
Дедупликация проверяет waveform и известные train-speaker IDs. Публикуются S/D/I/N,
корпусный lexical WER, шумовые вставки в минуту, ошибки исполнения и время. Для
RU допускается только явно условный bootstrap по предложениям, не заявление о
независимых дикторах. Полная приёмка SPEC не объявляется пройденной по этим данным.
