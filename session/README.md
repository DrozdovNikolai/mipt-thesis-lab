# 55NORD Session

Учебный веб-клиент редактора тренировочных сценариев для отчёта МФТИ. После входа пользователь выбирает сценарий, просматривает упражнения и меняет их порядок внутри модуля.

## Локальный запуск

Из корня проекта с Flutter 3.38.3 или совместимой версией выполните

```powershell
flutter pub get
flutter run -d chrome --web-hostname=127.0.0.1 --web-port=8818
```

Локальный клиент обращается к API Session на `http://127.0.0.1:8812/api`. Для входа нужна учётная запись этого сервера. Порт 8818 соответствует локальному origin исходного клиента.
## Размещение

```powershell
flutter build web --release
```

Содержимое `build/web` обслуживается статическим веб-сервером. На размещённом сайте путь `/api` должен вести на существующий бэкенд Session. Чтобы задать другой адрес, добавьте к команде запуска или сборки `--dart-define=API_BASE_URL=https://session.55nord.ru/api`. При раздельном размещении бэкенд должен разрешать origin клиента через CORS.
