# 55NORD Instructor

Отчётная версия рабочего места инструктора на TypeScript и React Native. Инструктор входит в систему, выбирает опубликованный сценарий и двух пилотов, просматривает план упражнений, выставляет оценки по компетенциям для каждого пилота и отправляет итоги тренировки. Сервер возвращает статус обработки.

Приложение предназначено для онлайн-сессии. Оценки до отправки и токены хранятся в памяти приложения. При перезагрузке страницы или перезапуске приложения несохранённые оценки теряются.
