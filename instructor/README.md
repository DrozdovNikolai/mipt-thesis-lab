# 55NORD Instructor

Отчётная версия рабочего места инструктора на TypeScript и React Native. Инструктор входит в систему, выбирает опубликованный сценарий и двух пилотов, просматривает план упражнений, выставляет оценки по компетенциям для каждого пилота и отправляет итоги тренировки. Сервер возвращает статус обработки.

Приложение предназначено для онлайн-сессии. Оценки до отправки и токены хранятся в памяти приложения. При перезагрузке страницы или перезапуске приложения несохранённые оценки теряются.

## Запуск в браузере

Проверенная среда — Node.js 22.19 и npm 10.9. Из корня репозитория выполните

```sh
npm ci
npm run web
```

Откройте адрес, который напечатает Expo. Войдите под учётной записью инструктора. Для демонстрации используйте выделенную учётную запись и учебный экипаж. Кнопка «Начать тренировку» создаёт запись на выбранном сервере.

## Планшет и сервер

Команда `npm start` запускает Expo. Для подключения устройства используйте Expo Go с поддержкой SDK 54 или совместимую сборку клиента. Для локального Android-эмулятора доступна команда `npm run android`, для iOS Simulator на macOS — `npm run ios`.

По умолчанию клиент использует RU-профиль исходного приложения по адресу `https://session.55nord.ru/api`. Для другого окружения скопируйте `.env.example` в `.env.local`, задайте `EXPO_PUBLIC_API_URL` и перезапустите Expo. При веб-разработке Metro передаёт запросы с локального пути `/api` выбранному серверу. Для опубликованной веб-сборки сервер должен разрешать запросы с домена приложения.

## Проверка

```sh
npm run typecheck
npx expo export --platform all
```

Сквозной сценарий пройден в браузере с тестовыми ответами API, включая выбор двух пилотов, независимые оценки, подтверждение и получение результата. У рабочего RU-сервера проверен ответ HTTP 401 на запрос профиля без авторизации. Проверка с записью итогов под действующей учётной записью и запуск на физических планшетах не выполнялись.
