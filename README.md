## Speech

В [speech/](speech/) находится модуль распознавания речи экипажа и инструктора. Он формирует черновик журнала тренировки для последующей проверки человеком.

- [Описание модуля и инструкции по запуску](speech/README.md)
- [Отчёты об экспериментах с распознаванием речи](speech/reports/README.md)

## Commander

В [commander/](commander/) находится веб-приложение на Vue 3 для работы с профилями пилотов, разбора тренировок и просмотра аналитики.

- [Локальный запуск, сборка и тесты](commander/README.md)
